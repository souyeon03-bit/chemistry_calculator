# 화학 실험 반응물 당량 및 투입량 계산기

기준 시약 대비 반응물의 당량(eq), 투입 질량, 물질량(mmol)을 자동 계산하는 단일 HTML 웹 계산기입니다.
서버나 외부 파일 없이 `index.html` 하나로 동작하며, 입력값은 브라우저 localStorage에 저장됩니다.

## GitHub Pages 배포
1. 이 폴더의 파일(`index.html`, `.nojekyll`, `README.md`)을 저장소 루트에 올립니다.
2. 저장소 Settings → Pages → Source를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 선택합니다.
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 접속할 수 있습니다.
